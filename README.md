# Rift Manager

Публичный репозиторий готовых выпусков Rift Manager. Исходный код приложения здесь не размещается.

## Загрузка

Скачивайте DMG из раздела **Releases** этого репозитория. Откройте образ и перенесите Rift Manager в Applications. Не запускайте приложение прямо из образа для постоянной работы.

Текущая сборка рассчитана на **macOS 13+ и Apple Silicon (arm64)**. Поддержка Intel в этом выпуске не заявлена. Windows-версия пока не выпущена.

ZIP в Releases предназначен для обновлений через Sparkle. Файлы `Source code (zip/tar.gz)`, автоматически показанные GitHub, содержат только документы этого репозитория.

## Обновления

Настройки → Обновления: ручная проверка или добровольное включение автоматической проверки. Обновления проверяются по подписи Ed25519. Перезапуск подтверждается пользователем.

Перед перезапуском завершите загрузки и операции с устройством. При ошибке обновления скачайте актуальный DMG из Releases.
