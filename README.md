# Rift Manager

Публичный репозиторий готовых выпусков Rift Manager. Исходный код приложения здесь не размещается.

## Загрузка

Текущий выпуск — **1.0.5 для macOS 13+ на Apple Silicon**. Скачайте `RiftManager-1.0.5-macOS.zip` в разделе [Releases](https://github.com/andruha2618/RiftManager-Releases/releases), распакуйте его и перенесите `Rift Manager.app` в папку «Программы». Для помощника App Store на Apple Silicon требуется Rosetta 2.

Windows-версия пока не выпущена. Файлы `Source code (zip/tar.gz)`, автоматически показанные GitHub, содержат только документы этого репозитория.

## Обновления

В настройках Rift Manager можно проверить обновления вручную или включить автоматическую проверку. Архивы обновлений проверяются подписью Sparkle Ed25519; перезапуск подтверждает пользователь.

Перед обновлением завершите загрузки и операции с устройством. Если обновление не установилось, скачайте актуальный ZIP из Releases.
